# ADR-0003：项目正式更名与命名规则

- 状态：已采纳（名称层面）
- 日期：2026-10-20

## 决策

项目工作名称从此前的 Unified Data Engine（UDE）更改为：

**广义流矢解码 — Generalized Stray-Arrow Decoding（GSAD）**

该名称是用户指定的项目名称。英文短语中的连字符按正式写法保留；缩写统一大写为 `GSAD`。

## 命名规则

- 仓库 / 顶层产品名：`GSAD`
- Rust 核心 crate：`gsad-core`
- 命令行 crate 与二进制：`gsad-cli` / `gsad`
- Rust crate 路径：`gsad_core`
- 能力 ID 命名空间：`gsad.<domain>.<name>`，例如 `gsad.codec.rle-v1`
- 实验性参考压缩格式签名：`GSARLE01`

## 不代表的内容

名称中的“解码”不意味着项目只处理媒体解码。项目范围仍包括解析、编码、压缩、解压、密码学操作、验证、转换、访问与存储。也不意味着所有功能必须在一个进程、一个算法或一个物理格式里实现。

此次更名不影响先前架构设计的技术方向；旧版文档仅保留作为决策历史，内容中的临时名称已统一更新到 GSAD。
