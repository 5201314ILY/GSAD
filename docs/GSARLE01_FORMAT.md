# GSARLE01 实验性格式规范

状态：仅用于验证 GSAD 流式处理契约；不适用于重要数据的长期归档。

## 布局

| 偏移 | 长度 | 字段 | 规则 |
|---:|---:|---|---|
| 0 | 8 字节 | Magic | 固定 ASCII 字节 `GSARLE01` |
| 8 及以后 | 每记录 2 字节 | Run record | `count`、`value` |

每个记录代表连续重复：`count` 是无符号字节，合法范围为 1–255；`value` 是重复的字节值。记录可以连续表达更长的重复序列。例如 300 个 `0x41` 可编码为 `(255,0x41)` 和 `(45,0x41)`。

空输入的压缩结果只有 8 字节 magic。

## 解码规则

- 输入不足 8 字节：`UnexpectedEof`。
- magic 不匹配：`CorruptData`。
- 记录只剩 count、没有 value：`UnexpectedEof`。
- count 为 0：`CorruptData`。
- 执行期间必须尊重输入上限、输出上限、取消令牌和扩张比约束。

## 设计限制

- 没有内置校验和、认证、索引或随机访问支持。
- 通用数据常常压缩效果很差，甚至变大。
- 此格式仅验证流式输入、输出上限和提交生命周期；以后引入成熟压缩算法不会要求保留该格式作为标准。
